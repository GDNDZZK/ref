`ref-web` 在浏览器中显示 ref。它是一个小型 Web 服务器：提供页面、为浏览器登录，并把浏览器的 WebSocket 帧原样转发给 `ref-server`。会话、工具和权限都留在后端，所以同一个会话可以同时在终端和浏览器标签页中打开。与 `ref` 一样，`ref-web` 通过 instance 文件找到运行中的后端，没有时启动同目录的 `ref-server`；这样启动的后端会在最后一个客户端断开后退出。

## 启动

```bash
ref-web                       # 监听 127.0.0.1:7480 并打开浏览器
ref-web ~/src/project         # 新会话在此目录启动
ref-web --port 8080 --no-open # 换端口，不打开浏览器
```

全部选项见[命令行](cli.zh-CN.md#ref-web)。页面把你传入的目录作为新会话的目录；没有传入时使用 `ref-web` 的启动目录。登录地址用 `?dir=` 传递这个目录；地址栏还可以带 `?session=<id>`（打开该会话）和 `?view=split`（分屏视图），并随你切换的会话而变化。

## 登录

启动时，`ref-web` 会打印登录地址并在浏览器中打开：

```
http://127.0.0.1:7480/login?token=…&dir=/home/you/src/project
```

打开这个地址会写入 cookie 并跳转到页面，因此 token 不会留在地址栏和浏览器历史中。之后在 cookie 过期前，直接打开 `http://127.0.0.1:7480/` 即可，不需要 token。

- cookie 名为 `ref_web_<端口>`，所以同一主机上的两个 `ref-web` 实例不会互相覆盖。它带 `HttpOnly` 和 `SameSite=Strict`，有效期 30 天。
- 它的值是保存在 `ref-web` 进程内存里的随机会话 id，不是登录 token：浏览器会把 cookie 发给同一主机的所有端口，如果 cookie 里放着 token，`localhost` 上的其他服务就能读到它。
- `ref-web` 重启后，旧的会话 id 失效。已打开的页面会得到 401，显示“未登录。请再运行一次 ref-web，它会重新打开登录地址。”并停止重连。再运行一次 `ref-web`（它会打开登录地址），页面即可恢复。

登录 token 在首次启动时生成，保存在 `<state 目录>/web/login-token`（64 位十六进制字符，权限 600；Unix 上发现权限更宽时会改回并提示），所以重启后登录地址不变。文件内容不是这种格式时，`ref-web` 报错 *does not hold a valid login token* 并退出。要换新的 token，先停止 `ref-web`，删除这个文件，再重新启动。用旧 token 登录的浏览器会退出登录。

## 每个端口一个实例

每个端口只运行一个 `ref-web`。该端口已有实例时再次启动，会打印登录地址（带本次的 `DIR`）并打开浏览器，然后以退出码 0 退出。已运行的实例保持它自己的 `--server`、`--mock` 和 `--host`，第二次启动的这些选项不生效。`ref-web` 靠 `/api/ping` 的应答识别自己的实例，应答用登录 token 签名。端口被其他程序占用时，`ref-web` 报错 *port N is in use by another program* 并以退出码 1 退出。

## 向局域网开放

`ref-web` 默认只监听 `127.0.0.1`。`--host ADDR` 可以监听其他地址，例如 `--host 0.0.0.0` 向局域网开放，此时会打印警告。

- 请用 **IP 地址**访问，例如 `http://192.168.1.20:7480/`。用主机名访问会被拒绝：`ref-web` 会用已知地址校验 `Host` 头，以防范 DNS rebinding。
- 没有 TLS。cookie 和你输入的所有内容都以明文传输，登录的人可以控制后端，而后端能在这台机器上运行命令。请改用 SSH 隧道，或带 TLS 的反向代理：

  ```bash
  ssh -L 7480:127.0.0.1:7480 server
  # 然后在本机打开 http://127.0.0.1:7480/
  ```

要使用在别处运行的后端，传入 `--server ws://host:port --token T`（见[在另一台机器上运行后端](cli.zh-CN.md#在另一台机器上运行后端)）。`--token` 必须与 `--server` 一起使用，`--server` 不能与 `--mock` 同时使用。

## 使用页面

页面与[桌面 GUI](gui.zh-CN.md)是同一套界面。本节列出页面有什么、与 GUI 有何不同；对话的详细说明见 GUI 一页，工具卡片、权限、图片、撤销和压缩的外观与行为相同。下文的按钮和命令名称取自简体中文界面。

**窗口**

- 左边的侧边栏列出运行中的会话、带搜索框的历史、MCP 服务器的状态和设置。可以隐藏（Alt+B），状态会被记住。窗口窄于 800 px 时，侧边栏变成覆盖在内容上的抽屉，且没有分屏视图。
- 运行中的会话优先显示名字，没有则显示标题，再没有则显示目录名。历史中的会话优先显示标题（压成一行），没有则显示名字，再没有则显示目录名，与终端界面一致。*运行中*列表随行数增高，只有在*历史*会少于三行时才出现滚动。
- *新建会话*在页面所用的目录里新建会话。要在其他目录新建，用旁边的文件夹按钮或命令*在其他文件夹新建会话…*（没有快捷键）。它会询问路径；按 Tab 或点击可补全子目录，子目录由后端列出。
- 命令面板（Ctrl+P，macOS 上 Cmd+P）可运行任何命令。不带参数的命令直接运行；重命名、更改目录、导出、变体、关闭指定会话和对等名称会先询问参数。输入框的 `/` 列表显示同一份命令，包括自定义命令。
- 关闭最后一个会话时，会在同一目录新建一个，页面不会空。没有 `/editor` 和 `/exit`。`/compact` 不再确认。
- 后端比页面旧时，顶部出现横幅和*重启后端*按钮。有运行中或等待授权的会话时按钮不可用。重启会停止后端，页面自动重连，`ref-web` 会启动已安装的新版后端。
- 你没有在看的会话（以及分屏视图中的任何会话）出错时，右上角弹出“会话名: 错误首行”。最多同时显示 4 条，info、警告、错误分别停留 3.5、6、8 秒；鼠标悬停暂停计时，相同的消息再次出现时重新计时而不叠加。当前会话的错误显示在对话末尾。

**分屏视图**

- Alt+W 或右上角的按钮为每个后台会话显示一个分块：没有其他客户端打开的存活会话，加上当前会话。点击分块或按 Alt+方向键移动焦点；命令作用于获得焦点的分块。用 Alt+Z 或分块上的按钮放大分块，此时按钮显示*返回分屏视图*。

**对话**

- Alt+R 展开/折叠全部思考块，Alt+O 展开/折叠全部工具详情；点击块头只改变这一块。`todo` 调用的待办清单不可折叠。等待授权的卡片始终展开。
- bash、read、grep 的输出最多显示 200 行，其余有*显示其余 N 行*。仍在运行的 bash 调用显示最后 20 行。卡片宽度不小于 560 px 时，还显示调用用时。
- 消息下方：作者、时间和 token；*复制*（该消息的文本），你自己的消息上还有*撤销*。Alt+Y 复制最后一条回复，Alt+U 撤销上一条提示并把它放回输入框。
- 滚动到靠近顶部（约 400 px）时，更早的消息会自动加载且视图不跳动；点击*加载更早的消息*效果相同。
- 授权键：获得焦点的会话（分屏视图中是任何分块）有待授权请求时，a 或 Enter 允许一次，s 本会话内允许，d 或 Esc 拒绝。请求出现 350 毫秒后按键才生效；之后在请求答完之前，其他字母键不会输入到输入框。打开的对话框保留自己的按键。
- 图片显示为缩略图，点击后放大查看，Esc 关闭。链接只对 http、https 和 mailto 打开；模型 Markdown 里的图片显示为链接，HTML 按文字显示，所以对话本身不会引发任何网络请求。

**输入框**

| 按键 | 作用 |
|---|---|
| Enter | 发送。会话忙时，提示在队列中等待；*撤回*可以取回。 |
| Shift+Enter、Ctrl+J | 换行。 |
| Tab、Shift+Tab | 下一个或上一个智能体。打开 `/` 或 `@` 列表时，Tab 是补全。 |
| Alt+T | 下一个模型变体（Ctrl+T 被浏览器占用）。 |
| Esc、Esc | 中断正在进行的一轮（1.5 秒内按第二次）。第一次 Esc 会先关闭已打开的列表、退出 shell 模式，或者在有工具调用正在等待延迟时，在该工具运行之前停止这一轮。 |
| ↑、↓ | 提示历史：输入框为空或光标在文本开头时按 ↑ 进入，浏览中在第一行继续 ↑；浏览中在最后一行按 ↓ 往后翻。 |
| Ctrl+C | 没有选区时清空输入框；有选区时是复制。 |
| 行首输入 `!` | shell 模式：这一行作为 shell 命令运行。输入框为空时按 Backspace 或按 Esc 退出该模式。 |

- 可以粘贴剪贴板中的图片，或把图片文件拖放到输入框（PNG、JPEG、GIF 或 WebP，单张不超过 20 MiB）。文本中会有 `[Image N]` 令牌，与终端界面相同。浏览器无法粘贴文件的路径或 `file://` 地址。
- `@` 列出会话目录下的文件，选中后插入 `@路径 `。
- 提示历史（500 条）保存在浏览器里（`localStorage`，键为 `ref.promptHistory`），不与终端界面或 GUI 共用。

## 快捷键

快捷键是 Alt+字母，按物理按键匹配，所以任何键盘布局下都能用。浏览器自己保留了 Ctrl+N、Ctrl+T 和 Ctrl+W，因此页面不使用它们。字母与 [GUI](gui.zh-CN.md#快捷键)相同，GUI 用 Ctrl+Shift 代替 Alt。

| 命令 | 快捷键 | `/` 命令 |
|---|---|---|
| 命令面板 | Ctrl+P（macOS 上 Cmd+P） | |
| 新建会话（同一目录） | Alt+N | `/new` |
| 切换会话（运行中 + 历史） | Alt+L | `/sessions` |
| 切换模型（仅此会话） | Alt+M | `/models` |
| 切换智能体 | Alt+A | `/agents` |
| 设置或轮换模型变体 | Alt+T | `/variant` |
| 压缩对话（不确认） | Alt+C | `/compact` |
| 撤销上一条提示 | Alt+U | `/undo` |
| 关闭此会话 | Alt+K | `/close` |
| 导出对话为 Markdown | Alt+X | `/export` |
| 复制最后一条回复（原文） | Alt+Y | `/copy` |
| 展开 / 折叠推理 | Alt+R | `/thinking` |
| 展开 / 折叠工具详情 | Alt+O | `/details` |
| 分屏视图 | Alt+W | `/watch` |
| 显示 / 隐藏侧边栏 | Alt+B | `/sidebar` |
| 放大当前分块（分屏视图） | Alt+Z | |
| 快捷键和命令 | Alt+H | `/help` |

| 移动分块焦点（分屏视图） | Alt+方向键 | |

*设置或轮换模型变体*不带参数时切换到下一个变体。帮助对话框（Alt+H）由命令列表生成，所以显示的总是实际有效的按键。对话框打开时，它独占键盘；只有 Ctrl+P 仍可打开和关闭命令面板。macOS 上，输入框内的 Alt+方向键仍然是按词移动光标。

## 通知

当你没有在看的会话需要工具权限、结束一轮或以错误结束一轮时，页面可以显示系统通知。屏幕上正在看的会话不会通知。点击通知会打开对应的会话。正文是“等待授权使用 {工具}”、“已完成”或“因错误而停止：{错误}”（页面语言为英文时是 *Waiting for permission to use {tool}*、*Finished*、*Stopped with an error: {error}*）。

- 需要浏览器允许。页面顶部的提示条会问一次（*允许*或*暂不*；选了*暂不*会记在 `localStorage` 里），设置里有同样的按钮。
- 浏览器只在 `localhost`、`127.0.0.1` 和 `https` 页面显示通知。通过局域网中的普通 `http` 地址访问，或浏览器禁止了通知时，只有标签页标题和标签页图标会提示需要处理。
- 设置里有总开关和三个分类：工具需要授权、一轮对话结束、一轮对话出错结束。默认全部打开。

## 设置

按 Alt+S 或点侧边栏里的设置按钮打开：主题（跟随系统、亮色或暗色）、语言（跟随系统、English 或 简体中文）和通知。设置保存在浏览器里（`localStorage`，键为 `ref.settings`，其中也包括侧边栏是否显示），同一浏览器的各个标签页共享。已保存的设置里有错误的值时，该值改用默认值，其余保留。

## 连接

- `ref-web` 每 30 秒向每个标签页的 WebSocket 发一次 ping。某个标签页 60 秒内没有任何帧（既没有 pong，也没有普通消息），或者因为浏览器不读取而 60 秒内发不出一帧时，该标签页的连接及其到后端的连接都会被关闭。因此笔记本休眠或断网后，后端不会留下失效的会话订阅。
- 连接断开时，页面会自动重连。如果 `ref-web` 重启过，页面会先请求 `/api/info`；得到 401 说明 cookie 已失效，页面就显示*未登录……*而不再重试（见[登录](#登录)）。`ref-web` 没有运行时，页面会一直重试。

## 已知限制

- 通知需要 `localhost` 或 `https`（见上）。
- 有些浏览器把 Alt+←/→ 用作后退和前进。用 Alt+方向键移动分块焦点，还没有在所有浏览器里试过。
- 某些键盘布局下，Alt+字母会产生特殊字符；页面按物理按键匹配，不看产生的字符。
- 提示历史和设置按浏览器保存，不与终端界面或 GUI 共用。
- 工具的参数和输出按 UTF-8 文本显示。

## 开发页面

页面在 `web/` 中（Vue 3、TypeScript、Vite、pnpm）。`ref-web` 嵌入构建后的文件，构建方法见[开发](development.zh-CN.md#构建)。在构建 `ref-web`，或用 `--workspace` 运行 `cargo build`、`cargo test`、`cargo clippy` 之前，要先在 `web/` 中运行 `pnpm install && pnpm build`，否则 `build.rs` 会报错。

```bash
cd web
pnpm install
pnpm dev                  # Vite 开发服务器，127.0.0.1:5173
```

`pnpm dev` 把 `/ws`、`/api` 和 `/login` 转发到 `127.0.0.1:7480` 上的 `ref-web`。先启动 `ref-web --no-open`（或 `ref-web --mock --no-open`），再用登录地址中的 token 通过开发服务器登录：`http://127.0.0.1:5173/login?token=…`。全程使用 `127.0.0.1` 而不是 `localhost`，因为 cookie 属于某一个主机名。
