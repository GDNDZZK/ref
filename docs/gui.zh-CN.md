`ref-gui` 在桌面窗口中显示 ref（Qt Quick）。与 `ref` 和 `ref-web` 一样，它只负责显示会话：会话运行在 `ref-server` 中，所以同一个会话可以同时在终端、GUI 和浏览器标签页中打开。没有运行中的后端时，`ref-gui` 会启动它所在文件夹里的 `ref-server`；这样启动的后端在最后一个客户端断开后退出。

下文中的按钮和命令名称取自简体中文界面。

## 安装

从[最新发布版](https://github.com/GDNDZZK/ref/releases/latest)下载 `ref-gui-<version>-<platform>`（或 `ref-all-…`）；README 的[安装](../README.zh-CN.md#安装)一节列出了各平台以及各系统的要求。压缩包里是一个文件夹：

| 系统 | 内容 |
|---|---|
| Linux | `ref-gui`、`ref-server`、`lib/`、`plugins/` 和 `qml/`（Qt 和其他库）、`qt.conf`、`ref-gui.desktop`、`ref.png` |
| macOS | `ref.app`，里面有 `ref-server` 和全部库 |
| Windows | `ref-gui.exe`、`ref-server.exe`、Qt 和 Visual C++ 运行库的 DLL、`plugins\` 和 `qml\` |

请保持文件夹完整，并从它所在的位置运行程序；整个文件夹可以移动。不需要安装，也不需要管理员权限。除系统自带的库之外，GUI 需要的一切都在文件夹里，所以它不会使用系统上安装的 Qt。

Linux 上程序需要 glibc 2.38 和 GCC 13 的 C++ 运行库（Ubuntu 24.04、Debian 13、Fedora 39、Arch 及更新版本），运行在 X11 上，或通过 XWayland 运行。不包含 Qt 的 Wayland 插件。

## 启动

```bash
ref-gui                       # 在当前目录新建会话
ref-gui ~/src/project         # 在另一个目录新建会话
ref-gui -c                    # 继续此目录最近的会话
ref-gui -s ses_01a1…          # 按 id 打开会话（运行中的或历史中的）
ref-gui -w                    # 启动即进入分屏视图
ref-gui --agent plan --model openai/gpt-5#high
```

| 选项 | 含义 |
|---|---|
| `DIR` | 新会话的目录（默认：当前目录）。 |
| `-c`, `--continue` | 继续此目录最近的会话。 |
| `-s`, `--session ID` | 按 id 打开会话，运行中的或历史中的。 |
| `-w`, `--watch` | 启动即进入所有运行中后台会话的[分屏视图](#分屏视图)。 |
| `--agent NAME` | 新会话使用的智能体。 |
| `--model provider/model[#variant]` | 新会话使用的模型。 |
| `--server ws://host:port` | 连接指定的后端，而不是查找或启动后端。 |
| `--token T` | `--server` 的 token。必须与 `--server` 一起使用。 |
| `--mock` | 使用带预设脚本的私有假后端（开发用，见 [Mock 后端](development.zh-CN.md#mock-后端)）。不能与 `--server` 同时使用。 |
| `-V`, `--version`, `-h`, `--help` | 版本和帮助。 |

窗口标题是 `ref`。Windows 上的 `ref-gui.exe` 是纯窗口程序，不会打开控制台，所以 `--help` 和 `--version` 在那里没有输出。

## 窗口

窗口左边是侧边栏，右边是内容区：一个会话，或[分屏视图](#分屏视图)。

- **运行中** 列出本窗口的存活会话，新建的在前。**历史** 列出后端保存的会话，按最后更新时间排列；搜索框在最近的 200 条里过滤。单击打开会话。双击运行中的会话，或用右键菜单，可以重命名或关闭；历史条目的右键菜单可以删除它。
- 运行中的会话优先显示你起的名字，没有则显示标题，再没有则显示目录名。历史中的会话优先显示标题（压成一行），没有则显示名字，再没有则显示目录名，与终端界面一致。*运行中*列表随行数增高，只有在*历史*会少于三行时才出现滚动。
- *新建会话*按钮在当前会话的目录里新建会话。旁边的文件夹按钮，或命令*在其他文件夹新建会话…*，会先询问目录。
- 关闭仍在工作的会话会先确认；对话保留在历史中。关闭最后一个会话时，会在同一目录自动新建一个，窗口不会空。
- 侧边栏可以隐藏和再次显示（Ctrl+Shift+B），状态会被记住。
- 命令面板（Ctrl+P）列出全部命令，边输入边过滤。不带参数的命令直接运行，其余的（重命名、更改目录、按名字关闭会话、peers）会先询问参数。它与输入框的 `/` 列表是同一份命令，包括你的[自定义命令](configuration.zh-CN.md)（分组*自定义*）。没有快捷键的命令有：*在其他文件夹新建会话…*、*重命名会话*、*更改此会话的工作目录*、*关闭运行中的会话*、*对等会话*相关命令（`peers`）和 *MCP 服务器*。没有 `/editor` 和 `/exit` 命令。
- 后端比 GUI 旧时，内容区顶部出现横幅和*重启后端*按钮。有运行中或等待授权的会话时按钮不可用。重启会停止后端，GUI 随后再启动已安装的后端。
- 窗口角落的提示会报告你没有在看的会话出错，以及导出等操作的结果。

## 分屏视图

分屏视图（Ctrl+Shift+W、右上角按钮或 `ref-gui -w`）为每个后台会话显示一个分块：没有其他客户端打开的存活会话，加上当前会话。只有获得焦点的分块显示输入框（与终端界面一致），其余分块把空间留给对话；它们仍显示状态行和排队中的消息，输入框隐藏期间草稿、附件和 shell 模式都会保留。点击分块使其获得焦点并显示输入框，Alt+方向键移动焦点；侧栏选中获得焦点的分块所属的会话，并用一条竖线标出所有分块；命令作用于获得焦点的分块。双击分块的标题栏，或点它的放大按钮（Ctrl+Shift+Z），放大该分块；再按 Ctrl+Shift+Z 或点右上角的 *退出放大*按钮退出放大。Esc 不用于退出放大，因为 Esc 留给输入框和授权提问。没有后台会话时，视图会提示。

## 对话

- 你的提示、模型的回复、思考和工具调用显示在同一列里。每条消息下方有一行小字，显示作者（智能体、模型、变体）、用时和 token（输入含缓存读写，以及输出）。被中断和失败的消息有标记。悬停时这一行显示*复制*，你自己的消息上还有*撤销*。
- 模型输出时，视图跟随对话底部。向上滚动（滚轮、触摸板、滚动条）会停止跟随，并出现 *跳到最新*按钮；滚到底部会再次跟随。
- 打开会话时只加载最近一批消息。滚动到靠近顶部时，更早的消息会自动加载；顶部的 *加载更早的消息*一行点击也能加载，加载失败时显示错误并可重试。
- 压缩之后，分隔块标出模型上下文的起点。分隔块之前的消息变淡：你仍然可以阅读，但模型已经看不到了。分隔块里的摘要可以折叠和展开。
- 不是你发的消息会有标记：来自其他会话（*来自“名称”的消息*）、由父会话创建、系统提醒，或 `!` shell 命令的输出。切换智能体时，会有一条提醒告诉模型。
- 思考块在模型思考时展开，结束后折叠。点击块头可单独展开或折叠；命令 *展开/折叠思考内容*（Ctrl+Shift+R）和*展开/折叠工具详情*（Ctrl+Shift+O）一次处理全部，并覆盖你手动展开的块。
- 输入框上方的状态行显示会话在做什么（处理中、正在运行工具、正在压缩上下文…、等待你的授权）和本轮用时，请求重试时显示倒计时，并有一个上下文占用条。达到建议压缩点时占用条变黄，达到自动压缩点时变红；悬停可看数值。会话自身的错误显示在对话末尾，直到你发送下一条提示。

**工具卡片**

- 每个工具调用是一张卡片：状态标记、工具图标和名称、用途、参数中的一行（命令、路径、模式、URL……）、状态、用时和开始时间。点击块头展开。失败的调用在折叠时显示错误的第一行。
- 展开的卡片按工具显示有用的内容：edit 和 write 显示 diff；bash 显示命令、输出和退出码（非 0 为红色标签，超时、取消、截断也有标签）；read 和 grep 显示带行号的行（命中行高亮，不相邻处有省略标记）；find 显示路径；webfetch 显示状态码、类型和大小，并有*在浏览器中打开*；发给其他会话的消息显示收件人和内容。`todo` 调用的待办清单始终展开。其他工具以文本显示输入和输出。
- 长输出截断为 200 行，并有*再显示 N 行*；代码行可横向滚动。仍在运行的 bash 调用只显示最后 20 行。输出带*复制*按钮。
- 正在等待延迟的工具显示一个圆环和*取消*按钮。点*取消*，或在输入框按一次 Esc，会在该工具运行之前停止这一轮。

**授权**

- 需要授权的调用会自动展开，显示命令或路径和三个按钮：*允许*（a）、*本会话内允许*（s）、*拒绝*（d）。会话获得焦点时也可以按 a 或 Enter、s、d 或 Esc，光标在输入框里时同样有效。请求出现 350 毫秒后按键才生效，这样你正在输入的文字不会误答；在所有请求答完之前，字母键不会进入输入框（Ctrl、Alt 快捷键和编辑键仍然可用）。多个调用同时等待时，先答最早的，卡片上显示*另有 N 个在等待*。分屏视图中按键作用于获得焦点的分块。

**图片**

- 你附加的图片和工具返回的图片显示为 72 px 高的缩略图。点击后在对话上方放大查看；Esc、点击图片外面或关闭按钮都能收起，光标回到输入框。图片在需要时才从后端获取。

**撤销**

- *撤销上一条提示*（消息下方的*撤销*按钮，或 Ctrl+Shift+U）把对话回退到该提示之前，并把提示连同图片放回输入框，便于修改后重新发送。被删除的消息会淡出。模型修改过的文件**不会**恢复。

**链接与不受信任的内容**

- 消息中的链接在浏览器中打开，仅限 http、https 和 mailto。模型 Markdown 里的图片（`![]()`）显示为链接，不会加载；消息里的 HTML 标签按文字显示。对话中的任何内容都不会让 GUI 自行访问网络。

## 输入框

| 按键 | 作用 |
|---|---|
| Enter | 发送。会话忙时，提示会在输入框上方的队列里等待。 |
| Shift+Enter、Ctrl+J | 换行。 |
| Tab、Shift+Tab | 下一个或上一个智能体。打开 `/` 或 `@` 列表时，Tab 是补全。 |
| Esc、Esc | 中断正在进行的一轮（1.5 秒内按第二次）。第一次 Esc 会先关闭已打开的列表或退出 shell 模式。 |
| ↑、↓ | 浏览提示历史：输入框为空或光标在文本开头时按 ↑ 进入，浏览中在第一行继续 ↑；浏览中在最后一行按 ↓ 往后翻。 |
| Ctrl+C | 没有选区时清空输入框（20 个字符以上的内容会先存入历史）；有选区时是复制。 |
| 行首输入 `!` | shell 模式：这一行作为 shell 命令运行。输入框为空时按 Backspace，或按 Esc，退出该模式。 |

macOS 上，表中的 Ctrl 是 Cmd。

- 输入框下方的标签显示智能体、模型和变体。点击标签进行选择；标签只在后端确认后才变化。变体没有 Ctrl+T，请用 Ctrl+Shift+T 或点击变体标签。
- `/` 列出命令，与命令面板相同，包括自定义命令。`@` 列出会话目录下的文件（遵守 `.gitignore`），选中后插入 `@路径 `。
- 图片：Ctrl+V 粘贴剪贴板中的图片，粘贴图片文件的路径或 `file://` 地址，或把图片文件拖放到输入框。支持 PNG、JPEG、GIF 和 WebP，单张不超过 20 MiB。每张图片在文本上方有一个带移除按钮的缩略图，在文本里是一个 `[Image N]` 令牌，与终端界面相同。
- 会话忙时发送的提示在输入框上方的队列条里等待。点自己提示上的*撤回*会把它连同图片放回输入框；后端已经取走时，GUI 会提示“已经发送，无法再撤回该提示”。
- 提示历史是状态目录中的文件 `prompt-history.jsonl`（500 条），与终端界面共用。shell 行带着 `!` 保存。

## 通知

当你没有在看的会话需要工具授权、结束一轮或以错误结束一轮时，GUI 可以显示系统通知。会话不在屏幕上，或窗口不在前台时，都算“没有在看”。点击通知会打开对应的会话。标题是会话标题（没有标题时为 `ref`）；正文是“等待授权使用 {工具}”、“已完成”或“因错误而停止：{错误}”（界面语言为英文时是 *Waiting for permission to use {tool}*、*Finished*、*Stopped with an error: {error}*）。

在*设置*里，一个总开关和三个分类（工具需要授权、一轮对话结束、一轮对话出错结束）决定显示哪些。系统无法显示通知时，设置里会说明，并改为让任务栏图标闪烁。

| 系统 | 实现 |
|---|---|
| Linux | 桌面通知服务（`org.freedesktop.Notifications`）。没有这个服务时不可用。 |
| Windows | toast 通知。程序会在 `HKCU` 下注册自己的 AppUserModelId；只有开始菜单里有 ref 的快捷方式时，Windows 才会显示 toast。 |
| macOS | UserNotifications。只有打包好的 `ref.app` 并在你允许它发送通知之后才可用。 |

如果你正在使用另一个界面，通知只会发给那个界面：后端把每条通知只发给一个客户端。

## 设置

用 Ctrl+Shift+S 或侧边栏底部的设置按钮打开。

- **主题：**跟随系统、浅色或深色。
- **语言：**跟随系统、English 或 简体中文。对话区和对话框都有翻译。
- **通知：**总开关和[上面](#通知)说明的三个分类。

设置保存在状态目录（[文件与目录](cli.zh-CN.md#文件与目录)）的 `gui.json` 里，同时保存侧边栏是否显示和窗口大小：

```json
{
  "theme": "system",
  "language": "system",
  "notifications": { "enabled": true, "permission": true, "turnDone": true, "turnError": true },
  "sidebar": { "visible": true },
  "window": { "width": 980, "height": 760 }
}
```

`theme` 取 `system`、`light` 或 `dark`；`language` 取 `system`、`en` 或 `zh_CN`。每次修改都会写入文件。文件无法读取时，会被改名为 `gui.json.bad`，改用默认值，并在设置对话框和窗口角落的提示里说明。有错误的值会逐个被忽略，保持默认值。

## 已知限制

- Windows 和 macOS 上的通知还没有在这两个系统上试过。
- Wayland 下，点击通知后窗口能否前置取决于桌面环境：没有 activation token 时，任务栏图标可能只会闪烁。
- Linux 上 Ctrl+Shift+U 可能被 IBus 的 Unicode 输入占用。按键没有反应时，请关闭 IBus 的这个按键，或使用消息下方的*撤销*按钮或 `/undo`。
- 在很长的会话中（视图上方或下方超过约 200 条消息），滚动条的长度是估算值，拖动时可能略有变化。
- 以非 0 退出码结束的 bash 调用，在卡片头里仍显示为完成；退出码在展开的卡片里。
- 对 GUI 没有专门视图的工具，单行摘要按字母顺序列出前三个普通参数，而终端界面按调用中的顺序。
- 工具的参数和输出按 UTF-8 文本显示。
- 没有 `/editor` 和 `/exit` 命令，最后一个会话关闭时 GUI 不会退出。

## 文件与后端

GUI 与 `ref` 使用相同的 instance 文件、配置和会话存储（[文件与目录](cli.zh-CN.md#文件与目录)），也使用相同的环境变量。

## 构建与开发

见开发文档中的 [GUI](development.zh-CN.md#gui) 一节。
