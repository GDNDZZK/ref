## 启动

```bash
ref                       # 在当前目录打开空白欢迎页
ref ~/src/project         # 指定另一个默认目录打开
ref -c                    # 继续此目录最近的会话
ref -s ses_01a1…          # 按 id 打开会话（运行中的或历史中的）
ref -w                    # 所有后台会话的分屏视图
ref --agent plan          # 为新会话预先选择智能体
ref --model openai/gpt-5#high -p "Explain src/main.rs"
```

全部参数见[命令行](cli.zh-CN.md#ref)。

## 会话与后端

ref 由两个程序组成。`ref-server`（后端）运行会话：调用 LLM、运行工具、保存历史并处理权限。`ref`（TUI）显示会话并发送你的输入。两者通过本地 WebSocket 通信。

启动 `ref` 时，它会依次按 `--server`、`~/.local/state/ref/tui.json` 中保存的默认后端来解析目标，否则连接到运行中的本地后端，没有时才按需启动 `ref-server`。以这种方式启动的本地后端会在最后一个 `ref` 窗口关闭时退出。其他显示会话的程序，例如桌面图形界面（[桌面 GUI](gui.zh-CN.md)）和浏览器界面（[Web 界面](web.zh-CN.md)），通过同一个 instance 文件找到同一个本地后端，所以一个会话可以同时在多个界面中打开。由其中一个界面启动的后端，会在最后一个客户端（无论哪种界面）断开后退出。后端退出时，正在运行的轮次也随之停止。只要还有至少一个客户端连着，即使没有窗口显示某个会话，它也会继续运行，因此你可以关闭一个窗口、再打开另一个，从会话当前的进度继续。想在没有任何窗口时让会话继续运行，请自己用 `ref-server` 启动后端（见[命令行](cli.zh-CN.md#ref-server)）；这样启动的后端不会自行退出。

- 不带 `-c`、`-s`、`-w` 或 `-p` 时，`ref` 启动后停留在空白欢迎页，不会自动创建会话（当前目录没有历史会话时传入 `-c` 会发出警告，而不是新建会话）。在欢迎页上，你可以在发送第一条提示前预先选择工作目录（`/cd`）、智能体（`tab`、`/agents`）、模型（`ctrl+x m`、`/models`）和变体（`ctrl+t`、`/variant`），也可以运行 `/new`（`ctrl+x n`）立即创建会话。
- 有前端连接时，会话处于**前台**，否则处于**后台**。点击侧边栏中当前已打开的会话行，或运行 `/detach`（`/background`、`/leave`），会将其挂到后台并返回空白欢迎页。
- 会话保存在 `~/.local/share/ref/sessions/`。`ctrl+x l` 列出运行中的会话和历史会话；打开旧会话会重新加载它。
- 多个窗口可以同时显示同一个会话。

## 界面

- **欢迎页 / 对话记录**：未打开会话时，显示当前目录、当前后端摘要以及可点击的 `Switch Backend…` 按钮；打开会话后，显示你的提示、模型的回复、推理内容和工具调用。
- 底部的**输入框**，旁边显示智能体、模型和变体。
- **侧边栏**（`ctrl+x b` 切换显示）：
  - **运行中的会话**，每个会话显示待办进度（`2/5`，全部完成时显示绿色的 `✓3/3`；已取消的项不计数），忙碌时还显示当前轮次已运行的时长。点击当前已打开的会话行会挂到后台并返回欢迎页。
  - **MCP 服务器**及其状态。
- **状态行**：会话正在做什么，以及本轮运行的时长。时长来自后端，因此切换会话后依然准确。请求处于重试等待时，点击状态行上的重试提示可立刻重试。

## 输入提示

| 输入 | 作用 |
|---|---|
| `enter` | 发送。 |
| `shift+enter`、`ctrl+j` | 换行。 |
| `/` | 命令列表及参数补全（参见[斜杠命令](#斜杠命令)）。 |
| `@` | 模糊匹配的文件列表；插入选中的路径（自定义命令参数内同样可用）。 |
| `!command` | Shell 模式：在会话目录中运行命令（限时 10 分钟）。命令及其输出作为你的消息加入对话，不触发 LLM 轮次。 |
| `ctrl+v` | 从剪贴板粘贴图片。粘贴图片文件的路径也会附加该图片（shell 模式除外）。 |
| `ctrl+x e` | 在 `$VISUAL` / `$EDITOR` 中编写提示（默认 `vi`，Windows 上为 `notepad`）。 |
| `↑` / `↓` | 提示历史，在输入框为空或光标位于边界时可用（shell 模式下仅筛选 `!` 命令）。 |
| `esc esc` | 中断会话。 |

**斜杠补全与拼写防误发。** 斜杠命令不区分大小写，并为 `/cd`、`/export`、`/models`、`/agents`、`/variant`、`/sessions`、`/close-session` 和 `/mcp`（以及自定义命令参数中的 `@file`）提供参数补全。可单独使用的斜杠命令（除 `/rename` 外的内置命令及自定义命令）按 `tab` 补全时不追加空格，按 `enter` 直接执行。未知的单个斜杠词（如 `/foo`）会被拦截并弹出警告与最接近的命令建议，不会误作为提示词发送给模型，原草稿保持不变。

**Shell 模式（`!`）。** 在空输入框中输入 `!` 进入 shell 模式（空框按 `backspace` 或按 `esc` 退出，已输入的文本保留）。命令词（行首、`|`、`&&`、`||`、`;` 之后，以及前置 `VAR=val` 赋值与 `sudo`、`env`、`nice`、`timeout` 等包装命令之后的实际程序）合并补全 `!` 历史与 `$PATH` 可执行程序，包含 `/`、`\` 或以 `.`、`~`、Windows 盘符开头时改为补全路径；参数词补全会话目录下的文件与子目录，对目录按 `tab` 会追加 `/` 并继续向下一级展开。shell 模式下 `tab` 和 `shift+tab` 绝不会切换智能体，`↑` / `↓` 只浏览 `!` 历史记录。在 `/cd`、`/export` 和 `!` shell 模式下，只有先用 `↑` / `↓` 显式选中了补全项时 `enter` 才会采纳补全，否则直接按输入原文执行（`tab` 始终采纳补全）。

**排队的提示。** 会话忙碌时发送的提示会显示在对话记录下方等待，在下一个安全点（当前工具步骤之后）送达。点击 `✕ remove` 可以撤回：它的文本和图片会回到输入框（如果你正在输入，则放在一个空行之后）。如果在此期间已经送达，会弹出提示说明。其他会话排队的消息和提醒也会列出，并标明发送者，但不能撤回。连接到该会话的每个窗口都会实时看到队列变化。

**撤销。** `ctrl+x u`、`/undo` 或提示下方的 `↶ undo` 会删除该提示及其之后的所有内容，并把提示的文本和图片放回输入框。工具修改过的文件**不会**恢复。

## 阅读对话记录

- 每条消息都显示时间：你的提示、每条回复（开始、结束、耗时和 token 数）以及每次工具调用（开始和耗时）。
- 折叠的工具调用显示工具名和模型给出的 `purpose`。点击可查看输入和输出。`ctrl+x d` 展开全部。
- 折叠的推理内容在一行中实时显示最新的字符。`ctrl+x t` 展开。
- 新内容输出时，视图自动跟随对话底部。向上滚动（鼠标滚轮、`page up` 或 `shift+↑`）停止跟随；滚回底部（`end` 或 `ctrl+alt+g`）重新跟随。
- 用鼠标选择文本：拖动选择，双击选词，三击选行。选择不会自动复制。用 `ctrl+c` 或右键复制（对话记录中的选择也可以用 `y` 复制）。在输入框中打字会替换选中的内容。
- 消息下方的 `⧉ copy` 复制其原始 markdown。`ctrl+x y` 复制最后一条回复。

## 斜杠命令

| 命令 | 作用 |
|---|---|
| `/new`（`/clear`） | 新建会话 |
| `/sessions [name or id]`（`/resume`、`/continue`） | 切换会话（打开选择器，或直接按名称、标题或 id 切换） |
| `/models [model]`（`/model`）、`/agents [agent]`（`/agent`） | 选择或直接切换模型或智能体 |
| `/variant [name]`（`/variants`、`/effort`） | 选择、设置或重置（`default`）模型变体（TUI 中 `ctrl+t` 轮换） |
| `/compact`（`/summarize`） | 压缩对话 |
| `/undo` | 撤销最后一条提示 |
| `/rename NAME` | 重命名会话 |
| `/cd [DIR]`（`/cwd`） | 更改会话目录（省略参数时打开交互式目录选择器） |
| `/detach`（`/background`、`/leave`） | 将当前打开的会话挂到后台（TUI、`ref-gui` 与 `ref-web` 均支持） |
| `/retry` | 立刻重试（跳过重试退避等待；点击重试状态行效果相同） |
| `/stash [name]` | 将全部运行中会话暂存为一个新分组（TUI、`ref-gui` 与 `ref-web`） |
| `/stashed`（`/groups`、`/stash-groups`） | 打开暂存分组管理器（`ref-web` 使用 `/stashed` 或 `/groups`） |
| `/backend`（`/server`） | 交互式切换后端连接，或在 TUI 中直接传入 `auto` / `URL [TOKEN]` 临时切换 |
| `/close` | 关闭当前会话 |
| `/close-session [name or id …]`（`/kill`） | 关闭运行中的会话（打开选择器，或按名称/id 一次关闭一个或多个） |
| `/export [PATH]` | 将对话记录导出为 markdown（默认为会话目录中的 `ref-session-<id>.md`） |
| `/copy` | 复制最后一条回复 |
| `/thinking`、`/details`、`/sidebar` | 开关 |
| `/watch`（`/split`） | 分屏视图 |
| `/mcp [server]`（`/mcps`） | MCP 服务器：状态、错误和工具（TUI 中按 `r` 刷新） |
| `/config`（`/configuration`） | 图形化 `ref.json` 编辑器与方案切换器（`ref-gui` 与 `ref-web`） |
| `/reload`（`/reload-config`） | 重新加载配置并同步更新运行中会话与 MCP 服务器 |
| `/editor` | 在 `$EDITOR` 中编写提示（TUI） |
| `/peers`、`/peers-name`、`/peers-inbox`、`/peers-outbox` | 参见[多会话协作](#多会话协作) |
| `/help` | 快捷键和命令 |
| `/exit`（`/quit`、`/q`） | 退出（TUI） |

配置中你自己定义的命令也会列出（参见[自定义命令](configuration.zh-CN.md#自定义命令)）。

**`/cd [DIR]`** 把当前会话（或创建会话前预选的工作目录）移到另一个目录：绝对路径、相对于当前目录的路径或 `~/…`。省略 `DIR` 时打开交互式目录选择器（`tab` 进入子目录，末尾为 `/` 时按 `backspace` 返回上一级）。对已打开的会话，项目配置和上下文文件会重新加载，并在对话中加入一条说明告诉模型目录已变更，不触发 LLM 轮次。会话忙碌时不允许执行。之后在此窗口中新建的会话也会从新目录启动。

**切换智能体**（`tab`、`ctrl+x a` 或 `/agents`）会在对话中加入一条说明告诉模型智能体已变更，不触发 LLM 轮次。连续快速切换共用同一条说明，切回原智能体则删除它。尚无对话的会话不加说明，只切换智能体。会话忙碌时，这条说明会在下一次请求之前加入。

**`/close`** 关闭当前会话并返回空白欢迎页，不会退出 `ref` 也不会自动新建替代会话（按 `ctrl+x q` 或运行 `/exit` 退出）。

**`/stashed`** 打开双栏暂存分组对话框（左侧为分组，右侧为成员；恢复分组或成员会将其作为后台运行中会话重新打开）：

| 按键 | 作用 |
|---|---|
| `tab`、`←` / `→` | 在分组栏与成员栏之间切换 |
| `↑` `↓`、`j` `k`、`ctrl+p` / `ctrl+n` | 移动选中项 |
| `enter` | 分组栏：进入成员栏（空分组则直接恢复）；成员栏：恢复成员（双击可恢复整组或单个成员） |
| `R` | 恢复选中的整个分组 |
| `c` / `s` / `r` / `l` | 新建空分组 / 暂存全部运行中会话 / 重命名分组 / 锁定或解锁分组 |
| `m` / `a` | 合并分组（分组栏）或移动成员到其他分组（成员栏） / 添加运行中会话到当前分组 |
| `shift+↑` / `shift+↓`、`K` / `J` | 调整成员在分组内的顺序（成员栏） |
| `x`、`delete`、`ctrl+d` | 删除分组（再按一次确认）或移除成员 |
| `g` | 刷新分组列表 |
| `esc`、`q`、`ctrl+c` | 关闭对话框（或取消删除确认、输入或目标选择） |

**`/backend`** 打开后端切换对话框，可临时切换端点（`enter`）、保存到 `~/.local/state/ref/tui.json` 作为默认后端（`ctrl+s`），或恢复本地自动发现（`ctrl+r`）。

## 分屏视图

`ref -w`、`ctrl+x w` 或 `/watch` 并排显示所有运行中的后台会话。

- 分屏开启期间，本窗口原来的前台会话会暂时隐藏，退出分屏视图后恢复；进入分屏时默认不聚焦任何分块，点击分块或按 `tab`、`alt+方向键` 移动焦点（再次点击已聚焦分块标题栏或空白区域可取消焦点）。
- 状态行中显示直接父会话创建者筛选胶囊（`All`、`User-created` 或 `By <创建者>`）：未聚焦任何分块时按 `f` 或点击该胶囊可循环切换筛选条件。
- 分块使用实线圆角边框（`╭─╮│╰─╯`）。由其他会话创建的子会话在标题栏显示 `⟲ <根会话>` 标签，并用固定的 8 色根任务调色板为未聚焦边框和标签着色；等待权限批准或 `question` 回答的分块以黄色警告色高亮。
- 输入文字并按 `enter` 向获得焦点的会话发送消息，`esc esc` 中断它，`ctrl+o` 放大它。聚焦分块同样支持斜杠补全、`@file` 引用与 `!` shell 模式（补全列表显示在分块输入框上方），其中输入的斜杠命令与 `!` shell 命令均作用于该分块的会话（仅在未打开补全列表且不处于 shell 模式时，`tab` 用于切换分块焦点）。
- 每个分块显示它的排队提示（`✕ remove` 撤回一条）；点击处于重试状态的分块标题栏可立刻重试。点击工具调用会在分块内显示其输入和输出，再次点击折叠；在分块对话记录中拖动鼠标可选中文本（`ctrl+c` 或右键复制，双击放大分块）。
- 鼠标滚轮滚动指针下方的分块。

## 多会话协作

会话之间可以互相通信。模型有相应的工具（参见[工具](tools.zh-CN.md#跨会话工具)），你也有在后端运行、不触发 LLM 轮次的命令：

- `/peers`（`/list-agents`）：其他运行中的会话及其状态、智能体、前台或后台、目录和排队的消息。
- `/peers-name [name]`：显示或设置此会话的名称。可以使用任意 Unicode 文本；名称在运行中的会话之间唯一。
- `/peers-inbox`：从其他会话收到的消息，包括仍在排队的。
- `/peers-outbox`：此会话发出的消息，以及每条消息是在排队、已送达还是已读。

具有 `can_spawn` 的智能体（默认是 `build`）可以启动后台会话、恢复已关闭的历史会话、给它们分派任务并关闭它们。可以在分屏视图中观察它们。

## 权限与延迟

当工具调用需要权限时，TUI 会显示该调用并询问：

- `a`：允许本次调用
- `s`：在本会话剩余时间内允许该工具的所有调用
- `d`：拒绝；模型会收到通知并继续

对于 `edit` 和 `write`，授权提示会在你回答前显示将要改动内容的预览 diff（在发出请求时计算；等待期间文件可能变化）。

工具设置了延迟时，运行前会显示倒计时，按 `esc` 取消该调用。两者都在配置中设置：参见[权限](configuration.zh-CN.md#权限)和[工具延迟](configuration.zh-CN.md#工具延迟)。

## 模型的提问

模型可以用 [`question` 工具](tools.zh-CN.md#question)请你做选择。TUI 会弹出对话框，会话等待你的回答；有未回答问题的会话在所有窗口的状态行显示 `? waiting for your answer`。后台会话也可以提问：它们会像待处理的权限请求一样出现在会话列表里，并发出通知。与权限请求一样，对话框刚打开的短时间内会忽略 `enter`、数字键和 `esc`，避免你正在输入的按键误答。

只有一个单选问题时，对话框是一个列表：

| 按键 | 作用 |
|---|---|
| `↑` `↓`、`j` `k` | 移动光标。光标起始在标有 `(default)` 的选项上，没有则在第一项。 |
| `enter` | 选中光标所在项并发送答案。 |
| `1`–`9` | 选中对应行并发送答案。 |
| `esc` | 放弃该问题；模型在没有答案的情况下继续。 |

有多个问题或有多选题时，顶部显示标签栏，每个问题一个标签，最后是 **Confirm** 标签：

| 按键 | 作用 |
|---|---|
| `tab`、`→` / `shift+tab`、`←` | 下一个 / 上一个标签。 |
| `enter` | 单选：选中并跳到下一个标签。多选：勾选或取消该项（`space` 和该行的数字键作用相同）。在 **Confirm** 上：发送全部答案。 |
| `esc` | 放弃全部问题。 |

多选题开始时，标有 `(default)` 的选项已被勾选。未回答的标签显示为暗色，**Confirm** 页把它们列为 `(not answered)`，仍可发送。点击某一行或某个标签与按键效果相同。

问题允许自定义答案时，最后一行是 **Type your own answer**。选中它后直接在该行输入；`enter` 保留文本（只有一个问题时同时发送答案），文本为空则取消，`esc` 退出输入但不放弃对话框。多选题里输入的文本会加到已勾选的选项后面，再次选中该行可收回。如果其他客户端先回答了，对话框会自动关闭。

如果客户端与 `ref-server` 的协议版本不一致，`ref-server` 会拒绝连接，并给出提示说明应当升级哪一端，或如何重启后端（运行 `ref-server --stop` 后重新启动）。
