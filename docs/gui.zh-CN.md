`ref-gui` 在桌面窗口中显示 ref（Qt Quick）。与 `ref` 和 `ref-web` 一样，它只负责显示会话：会话运行在 `ref-server` 中，所以同一个会话可以同时在终端、GUI 和浏览器标签页中打开。未传 `--server` 且 `gui.json` 中未保存默认 `backendUrl` 时，`ref-gui` 会连接运行中的本地后端，或在需要时按需启动它所在文件夹里的 `ref-server`；这样启动的后端在最后一个客户端断开后退出。

下文中的按钮和命令名称取自简体中文界面。

## 安装

从[最新发布版](https://github.com/GDNDZZK/ref/releases/latest)下载 `ref-gui-<version>-<platform>`（或 `ref-all-…`）；README 的[安装](../README.zh-CN.md#安装)一节列出了各平台以及各系统的要求。压缩包里是一个文件夹：

| 系统 | 内容 |
|---|---|
| Linux | `ref-gui`、`ref-server`、`lib/`、`plugins/` 和 `qml/`（Qt 和其他库）、`qt.conf`、`ref-gui.desktop`、`ref.svg` |
| macOS | `ref.app`，里面有 `ref-server` 和全部库 |
| Windows | `ref-gui.exe`、`ref-server.exe`、Qt 和 Visual C++ 运行库的 DLL、`plugins\` 和 `qml\` |

请保持文件夹完整，并从它所在的位置运行程序；整个文件夹可以移动。不需要安装，也不需要管理员权限。除系统自带的库之外，GUI 需要的一切都在文件夹里，所以它不会使用系统上安装的 Qt。

Linux 上程序需要 glibc 2.38 和 GCC 13 的 C++ 运行库（Ubuntu 24.04、Debian 13、Fedora 39、Arch 及更新版本）。在设置 `WAYLAND_DISPLAY` 时它会原生运行在 Wayland 上，否则自动回退到 X11 或 XWayland。

## 启动

```bash
ref-gui                       # 在当前目录打开窗口（不自动新建会话）
ref-gui ~/src/project         # 指定另一个默认目录打开窗口
ref-gui -c                    # 继续此目录最近的会话
ref-gui -s ses_01a1…          # 按 id 打开会话（运行中的或历史中的）
ref-gui -w                    # 启动即进入分屏视图
ref-gui --agent plan --model openai/gpt-5#high
```

| 选项 | 含义 |
|---|---|
| `DIR` | 新建会话的默认目录（默认：当前目录）。 |
| `-c`, `--continue` | 继续此目录最近的会话。 |
| `-s`, `--session ID` | 按 id 打开会话，运行中的或历史中的。 |
| `-w`, `--watch` | 启动即进入所有运行中后台会话的[分屏视图](#分屏视图)。 |
| `--agent NAME` | 新建会话默认使用的智能体。 |
| `--model provider/model[#variant]` | 新建会话默认使用的模型。 |
| `--server ws://host:port` | 连接指定的后端，而不是查找或启动后端。 |
| `--token T` | `--server` 的 token。必须与 `--server` 一起使用。 |
| `--mock` | 使用带预设脚本的私有假后端（开发用，见 [Mock 后端](development.zh-CN.md#mock-后端)）。不能与 `--server` 同时使用。 |
| `-V`, `--version`, `-h`, `--help` | 版本和帮助。 |

不带 `-c` 或 `-s` 时，`ref-gui` 打开后显示空白工作区（*未打开会话*），不会自动创建空会话（隐藏测试参数 `--smoke` 在未传会话参数时打印 `ready`，带 `-c` / `-s` 时打印 `attached <id>`）。窗口标题是 `ref`。Windows 上的 `ref-gui.exe` 是纯窗口程序，不会打开控制台，所以 `--help` 和 `--version` 在那里没有输出。

## 窗口

窗口左边是侧边栏，右边是内容区：一个会话、空白工作区（*未打开会话*，提供*选择文件夹新建会话…*和*新建会话*），或[分屏视图](#分屏视图)。

- **运行中** 列出本窗口的存活会话（默认新建的在前）。长按（约 280 ms）并上下拖动某一行可调整存活会话的排序（需要时会自动滚动），新创建的会话仍会排在最前，自定义顺序会保存在 `gui.json` 的 `sidebar.runningOrder`。**历史** 列出后端保存的会话，按最后更新时间排列；搜索框在最近的 200 条里过滤。单击打开会话；在单会话视图中再次单击当前已打开的会话，或从其右键菜单选择*挂到后台*，或运行 `/detach`（`/background`、`/leave` 或命令面板 → *将会话挂到后台*），会将该会话挂到后台而不停止运行，并回到*未打开会话*状态。双击运行中的会话，或用右键菜单，可以重命名或关闭；历史条目的右键菜单可以删除它。
- 运行中的会话优先显示你起的名字，没有则显示标题，再没有则显示目录名。历史中的会话优先显示标题（压成一行），没有则显示名字，再没有则显示目录名，与终端界面一致。*运行中*列表随行数增高，只有在*历史*会少于三行时才出现滚动。
- *新建会话*按钮（在工作区当前的默认目录里新建会话）左侧的 `36×36` **暂存**按钮会在存在至少一个分组时于图标内嵌显示分组数量：左键点击将全部运行中会话暂存为一个新分组（当前无运行中会话时打开暂存对话框），右键点击直接打开暂存对话框（也可通过 `/stash [name]` 或 `/stashed` / `/stash-groups` 打开）。双栏*暂存分组*对话框左侧为*运行中*、右侧为*已暂存分组*，支持拖放和动作菜单：新建分组、全部暂存、内联重命名、锁定/解锁分组、成员排序/移动/复制、合并未锁定分组、将成员拖入左侧*运行中*区域以恢复（拖到两栏之外则从分组移除），以及将单个成员或整组恢复为后台运行中会话。最右侧的文件夹按钮，或*选择文件夹新建会话…* / *在其他文件夹新建会话…*，会先询问目录，并将工作区的默认目录更新为所选文件夹。
- 关闭仍在工作的会话会先确认（包括从侧边栏和*会话*对话框关闭时）；对话保留在历史中。关闭最后一个打开的会话会回到*未打开会话*，不会自动新建替代会话（分屏视图中若关闭被隐藏的原前台会话，也只会清空前台引用，不会把后台分块抽出网格）。
- 侧边栏可以隐藏和再次显示（Ctrl+Shift+B），也可以拖动右边缘调整宽度（210–480 px；双击边缘恢复默认 264 px）。点击*待办*、*运行中*或*历史*标题行（或聚焦后按空格 / Return / Enter）可折叠和展开对应分区，收起后腾出的垂直空间会分配给其余展开的列表。上下拖动*待办*与*运行中*、或*运行中*与*历史*之间的分隔条可调整各分区高度（双击分隔条恢复自动分配）。侧边栏的显示状态、宽度、各分区折叠状态和自定义分区高度都会被记住。
- 侧栏顶部、*运行中*上方的*待办*区显示你正在看的会话（分屏视图中是获得焦点的分块）的待办清单和已完成数，如*待办 2/5*；已取消的事项不计入任何一个数字。长事项会换行；清单超出高度上限（默认侧栏三分之一高，或你拖动设置的高度）后在区内滚动；会话没有待办清单时该区隐藏。
- 命令面板（Ctrl+P）列出全部命令，边输入边过滤。不带参数的命令直接运行；选择*重命名会话*、*更改此会话的工作目录*、*将记录导出为 Markdown*、*设置或循环切换模型变体*或*关闭运行中的会话*会直接打开各自专用的对话框，在输入自定义命令参数时按 Esc 会返回命令列表。它与输入框的 `/` 列表是同一份命令，包括你的[自定义命令](configuration.zh-CN.md)（分组*自定义*）。没有快捷键的命令有：*在其他文件夹新建会话…*、*将会话挂到后台*（`/detach`）、*重命名会话*、*更改此会话的工作目录*、*关闭运行中的会话*、*对等会话*相关命令（`peers`）、*MCP 服务器*、*配置*（`/config`）和*重新加载配置*（`/reload`）。没有 `/editor` 和 `/exit` 命令。
- *配置*（`/config` 或 `/configuration`、侧边栏底部配置按钮，或*设置* → *编辑 ref.json…*）打开 860 px 宽的六分区可视化及原始 JSONC `ref.json` 编辑器，支持多方案切换（`ref.json.<n>.bak`）与 Ctrl+S 保存；`/reload`（`/reload-config` 或重新加载按钮）热重载配置并同步更新运行中会话与 MCP 服务器。详见[图形化配置编辑器与多方案](configuration.zh-CN.md#图形化配置编辑器与多方案)。
- **后端切换：** `/backend`（`/server`）、*设置* → *后端* → *切换后端…*，或断开状态胶囊上的*切换后端…*按钮可打开*切换后端*对话框，用于临时切换到其他 `ws://` / `wss://` 端点、将其（及可选令牌）保存为 `gui.json` 中的默认后端，或恢复本地自动发现。
- 后端比 GUI 旧时，内容区顶部出现横幅和*重启后端*按钮。有运行中或等待授权的会话时按钮不可用。重启会停止后端，GUI 随后再启动已安装的后端。
- 窗口角落的提示会报告你没有在看的会话出错，以及导出等操作的结果。
- *会话*对话框（Ctrl+Shift+L 或 `/sessions`）支持在*全部*、*用户创建*和*同一创建者*之间筛选，标出子会话的创建者，并同时按创建者名称和 id 搜索。

## 分屏视图

分屏视图（Ctrl+Shift+W、右上角按钮或 `ref-gui -w`）为每个后台会话显示一个分块：没有其他客户端打开的存活会话，不包含当前前台会话（当前会话在分屏期间隐藏，退出分屏后恢复）。进入分屏时默认不聚焦任何分块；点击分块或按 Alt+方向键移动焦点，再次点击已聚焦分块的标题栏或空白背景可取消选中。由其他会话创建的子会话会在标题栏显示 `⟲ <根会话>` 标签，并在未聚焦时按根任务着色边框和状态点；用户创建的分块保持无标记。只有获得焦点的分块显示输入框（与终端界面一致），其余分块把空间留给对话；它们仍显示状态行和排队中的消息，输入框隐藏期间草稿、附件和 shell 模式都会保留。侧栏选中获得焦点的分块所属的会话，并用一条竖线标出所有分块；命令作用于获得焦点的分块。双击分块的标题栏，或点它的放大按钮（Ctrl+Shift+Z），放大该分块；再按 Ctrl+Shift+Z 或点右上角的 *退出放大*按钮退出放大。Esc 不用于退出放大，因为 Esc 留给输入框、授权提问和模型的提问。没有后台会话时，视图会提示。

顶栏居中的**创建者筛选胶囊**按直接父会话筛选分块（*全部*、*用户创建*、*由 `<创建者>` 创建 ×* 及创建者筛选菜单）；右键点击分块标题栏也可快速选择*按 `<创建者>` 筛选分块*、*筛选由 `<标题>` 派生的分块*、*筛选子会话历史*和*显示全部分块*。点击未聚焦分块上的*跳到最新*按钮会直接滚到底部，不会聚焦该分块或打开输入框。

## 悬浮球

点击右上角的悬浮球按钮（`float-20`）、按 Ctrl+Shift+F，或运行 `/float`（`/floating`），可隐藏主窗口并进入始终置顶的两态悬浮球模式（在受支持的桌面环境下保持置顶，Wayland 下由合成器控制窗口层级与位置）：

1. **悬浮球（`56×56`）：** 紧凑的置顶圆形悬浮球，显示聚合状态点与运行中会话数，悬停时提供高亮样式反馈。可拖动位置（保存在 `gui.json` 的 `floatingBall` 中）；右键菜单提供*打开迷你面板*、*返回完整窗口*和*新建会话*。
2. **迷你对话面板（`380×520`）：** 点击悬浮球由同一窗口原地向内侧锚定展开（支持多显示器）。若当前无前台会话则直接展示运行中会话列表而不会自动将后台会话拉入前台；打开会话后显示单会话紧凑面板，顶栏提供*挂到后台*按钮（返回会话列表）、会话切换胶囊、*新建会话*、*收起为悬浮球*、*返回完整窗口*以及带忙碌确认保护的*关闭*按钮。

处于悬浮模式时，点击系统通知会恢复完整窗口并打开对应会话。

## 对话

- 你的提示、模型的回复、思考和工具调用显示在同一列里。每条消息下方有一行小字，显示作者（智能体、模型、变体）、用时和 token（输入含缓存读写，以及输出）。被中断和失败的消息有标记。悬停时这一行显示*复制*，你自己的消息上还有*撤销*。
- Markdown 表格渲染为带边框与表头底色的独立卡片，宽表格支持横向滚动、悬停*复制*按钮以及单元格内独立文本选中。
- 模型输出时，视图跟随对话底部。向上滚动（滚轮、触摸板、滚动条）会停止跟随，并出现 *跳到最新*按钮；滚到底部会再次跟随。
- 打开会话时只加载最近一批消息，更早的消息根据 `MessageLayoutMeta` 估算高度并以结构化骨架占位呈现，无需预先拉取完整消息体。滚动到靠近顶部（或点击*加载更早的消息*）时自动分页加载（默认每页 500 条），常驻滑动窗口大小可在*设置* → *消息窗口*（`gui.json` 中的 `messageWindowSize`）自定义，默认常驻 1000 条（视口前后保留约 500 条缓冲，贴底跟随状态收敛后保留最新窗口条数并释放被逐出消息的图片缓存）；设为 `0` 表示不限制并自动加载全部历史。加载失败时显示错误并可重试。
- 压缩之后，分隔块标出模型上下文的起点。分隔块之前的消息变淡：你仍然可以阅读，但模型已经看不到了。分隔块里的摘要可以折叠和展开。
- 不是你发的消息会有标记：来自其他会话（*来自“名称”的消息*）、由父会话创建、系统提醒，或 `!` shell 命令的输出。切换智能体时，会有一条提醒告诉模型。
- 思考块在模型思考时展开，结束后折叠。点击块头可单独展开或折叠；命令 *展开/折叠思考内容*（Ctrl+Shift+R）和*展开/折叠工具详情*（Ctrl+Shift+O）一次处理全部，并覆盖你手动展开的块。
- 输入框上方的状态行显示会话在做什么（处理中、正在运行工具、正在压缩上下文…、等待你的授权、等待你的回答）和本轮用时，请求重试时显示倒计时和可点击的重试图标按钮（点击，或在聚焦时按 Enter/Space 即可立刻重试），并有一个上下文占用条。达到建议压缩点时占用条变黄，达到自动压缩点时变红；悬停可看数值。会话有待办清单时，状态行还会显示正在做的事项（没有则显示下一个待办）和已完成数，如 *Check the workspace · 1/3*；全部完成时显示绿色的 *✓ 3/3*。已取消的事项不计入任何一个数字，侧栏和分块标题栏上的徽标也是如此。点击它会在状态行上方展开完整清单；按 Esc、点击别处或切换会话时收起。会话自身的错误显示在对话末尾，直到你发送下一条提示。

**工具卡片**

- 每个工具调用是一张卡片：状态标记、工具图标和名称、用途、参数中的一行（命令、路径、模式、URL……）、状态、用时和开始时间。点击块头展开。失败的调用在折叠时显示错误的第一行。折叠的 `edit` 和 `write` 卡片也会显示路径、`+`/`-` 行数、前 8 行 diff（以及 `+N more`）和编辑重映射警告；已结束的 `question` 卡片折叠时显示已选回答的紧凑摘要。
- 展开的卡片按工具显示有用的内容：edit 和 write 显示原始输入、完整 diff（含编辑警告）和输出；bash 显示命令、输出和退出码（非 0 为红色标签，超时、取消、截断也有标签）；read 和 grep 显示带行号的行（命中行高亮，不相邻处有省略标记）；find 显示路径；webfetch 显示状态码、类型和大小，并有*在浏览器中打开*；发给其他会话的消息显示收件人和内容。`todo` 调用的待办清单始终展开。其他工具以文本显示输入和输出。
- 长输出截断为 200 行，并有*再显示 N 行*；代码行可横向滚动。仍在运行的 bash 调用只显示最后 20 行。输出带*复制*按钮。
- 正在等待延迟的工具显示一个圆环和*取消*按钮。点*取消*，或在输入框按一次 Esc，会在该工具运行之前停止这一轮。

**授权**

- 需要授权的调用会自动展开，显示命令或路径（对 `edit` 和 `write` 还会显示创建请求时计算的*预览* diff）和三个按钮：*允许*（a）、*本会话内允许*（s）、*拒绝*（d）。会话获得焦点时也可以按 a 或 Enter、s、d 或 Esc，光标在输入框里时同样有效。请求出现 350 毫秒后按键才生效，分块获得焦点、被放大或切换显示另一个会话后也要再等 350 毫秒，这样你正在输入的文字或点击分块的那一下不会误答；在所有请求答完之前，字母键不会进入输入框（Ctrl、Alt 快捷键和编辑键仍然可用）。多个调用同时等待时，先答最早的，卡片上显示*另有 N 个在等待*。分屏视图中按键作用于获得焦点的分块。

**提问**

- 模型向你提问（`question` 工具）时，该会话的状态行上方、对话下方会出现一张卡片，单会话视图和分屏视图的每个分块里都有，不论分块是否获得焦点。标题是 `?` 加问题的简短标题，下面是问题和选项。每个选项有序号和说明，默认选项标有*（默认）*并已预选。卡片随内容增高，窗格太小时选项可滚动。侧栏、分块标题栏和状态行显示*等待你的回答*，并带问号图标。
- 只有一个单选问题时，卡片就是一个列表：点击选项（或按 Enter）立即作答。有多个问题，或问题允许多选时，每个问题一个标签页，最后是*确认*页。单选页上点击选项即选中并跳到下一页；多选页上选项是复选框，默认项已勾选。*确认*页列出各问题的回答，没有回答的标为*未回答*；点*提交*（或按 Enter）发送，未回答的问题按空回答发送。
- 后端接受自由文字时，最后一个选项是*输入你自己的回答*。点它变成文本框：Enter 采用文字（空文字不算回答），Esc 回到列表。单选时输入的文字替换已选的选项；多选时追加，再选一次这一行就撤回。
- *忽略*或 Esc 表示不作答，模型会在没有回答的情况下继续。回答发出后卡片变暗（*正在发送…*），后端报告该问题已结束后才消失。后端拒绝回答时，原因显示在会话顶部的消息里，卡片保留。如果另一个窗口或终端界面先答了，卡片会直接消失，不提示。
- 按键与授权一致：↑ ↓ 或 j k 移动高亮（到头即停），Enter 或空格选中或勾选高亮的选项，1 到 9 按序号选择，← →、Tab 和 Shift+Tab 切换标签页，Esc 忽略。提问出现 350 毫秒后按键才生效（会话获得焦点后同样重新计时，与授权相同），且要求会话获得焦点（分屏视图中是获得焦点或已放大的分块），光标在输入框里时同样有效。回答之前其他输入不会进入输入框（Ctrl、Alt 快捷键和编辑键仍然可用），按住不放的键不会作答。输入自己的回答时，按键归文本框。鼠标在每个分块里都能用。

**图片**

- 你附加的图片和工具返回的图片显示为 72 px 高的缩略图。点击后在对话上方放大查看；Esc、点击图片外面或关闭按钮都能收起，光标回到输入框。图片在需要时才从后端获取。

**撤销**

- *撤销上一条提示*（消息下方的*撤销*按钮，或 Ctrl+Shift+U）把对话回退到该提示之前，并把提示连同图片放回输入框，便于修改后重新发送。被删除的消息会淡出。模型修改过的文件**不会**恢复。

**链接与不受信任的内容**

- 消息中的链接在浏览器中打开，仅限 http、https 和 mailto。模型 Markdown 里的图片（`![]()`）显示为链接，不会加载；消息里的 HTML 标签按文字显示。对话中的任何内容都不会让 GUI 自行访问网络。

## 输入框

| 按键 | 作用 |
|---|---|
| Enter | 发送（在 `/cd`、`/export` 和 `!` shell 模式下，除非已用 ↑/↓ 显式选中补全项，否则按输入原文执行）。在可单独运行的 `/` 补全列表上，Enter 直接执行所选命令。会话忙时，提示会在输入框上方的队列里等待。 |
| Shift+Enter、Ctrl+J | 换行。 |
| Tab、Shift+Tab | 下一个或上一个智能体（非 shell 模式下）。在 `/`、`@` 和 `!` shell 模式下，Tab 进行补全（可单独使用的斜杠命令不自动补空格，目录补全可继续向下一级展开）。 |
| Ctrl+T | 循环切换模型变体。 |
| Esc、Esc | 中断正在进行的一轮（1.5 秒内按第二次）。第一次 Esc 会先关闭已打开的列表或退出 shell 模式（保留已输入的文本）。 |
| ↑、↓ | 浏览提示历史（shell 模式下仅筛选 `!` 记录）：输入框为空或光标在文本开头时按 ↑ 进入，浏览中在第一行继续 ↑；浏览中在最后一行按 ↓ 往后翻。 |
| Ctrl+C | 没有选区时清空输入框（20 个字符以上的内容会先存入历史）；有选区时是复制。 |
| 行首输入 `!` | shell 模式：这一行作为 shell 命令运行，命令词支持 `!` 历史与 `$PATH` 程序补全（包括 `VAR=val` 环境变量以及 `sudo`、`env`、`nice`、`timeout` 等包装命令之后的实际程序），参数词支持文件/目录补全。输入框为空时按 Backspace，或按 Esc，退出该模式。 |

macOS 上，表中的 Ctrl 是 Cmd。

- 输入框下方的标签显示智能体、模型和变体。点击标签进行选择；标签只在后端确认后才变化。按 Ctrl+T 可直接循环切换变体，按 Ctrl+Shift+T 打开变体选择器，也可直接点击变体标签。
- `/` 在框首或空白之后都可触发命令补全，不区分大小写地匹配命令（包括单数别名 `/model` 与 `/agent`、直接带参的 `/models <m>`、`/agents <a>`、`/variant <v|default>`、`/sessions <s>`、`/close-session <s…>`），并为 `/cd`、`/export`、`/models`、`/agents`、`/variant`、`/sessions` 和 `/close-session`（以及自定义命令参数中的 `@file`）补全参数。除 `/rename` 外的斜杠命令均支持按 Tab 无空格补全、按 Enter 直接执行；未知的单个斜杠词 `/foo` 会被拦截并弹出警告与相近命令建议，不会误作为提示词发送。`@` 列出会话目录下的文件（遵守 `.gitignore`），选中后插入 `@路径 `。
- 图片与文件：Ctrl+V 粘贴剪贴板中的图片，粘贴文件路径或 `file://` 地址，或把任意文件拖放到输入框。支持的图片（PNG、JPEG、GIF 和 WebP，单张不超过 20 MiB）会在文本上方显示带移除按钮的缩略图，并在文本里插入原子化的 `[Image N]` 令牌（按当前输入草稿从 1 编号、清空附件后重新归零，并在撤销/重做时同步恢复或移除附件；光标不会落入令牌内部，框选自动覆盖整枚令牌，Backspace/Delete 整枚删除），与终端界面相同；其他已存在的本地文件会在光标处插入路径。
- 提示历史是状态目录中的文件 `prompt-history.jsonl`（500 条），与终端界面共用。shell 行带着 `!` 保存。

## 通知

当你没有在看的会话需要工具授权、提问、结束一轮或以错误结束一轮时，GUI 可以显示系统通知。会话不在屏幕上，或窗口不在前台时，都算“没有在看”。点击通知会打开对应的会话。标题是会话标题（没有标题时为 `ref`）；正文是“等待授权使用 {工具}”、“提问：{问题}”（第一个问题）、“已完成”或“因错误而停止：{错误}”（界面语言为英文时是 *Waiting for permission to use {tool}*、*Asks: {question}*、*Finished*、*Stopped with an error: {error}*）。

在*设置*里，一个总开关和三个分类（会话在等你，即授权或提问；一轮对话结束；一轮对话出错结束）决定显示哪些。系统无法显示通知时，设置里会说明，并改为让任务栏图标闪烁。

| 系统 | 实现 |
|---|---|
| Linux | 桌面通知服务（`org.freedesktop.Notifications`）。没有这个服务时不可用。 |
| Windows | toast 通知。程序会在 `HKCU` 下注册自己的 AppUserModelId；只有开始菜单里有 ref 的快捷方式时，Windows 才会显示 toast。 |
| macOS | UserNotifications。只有打包好的 `ref.app` 并在你允许它发送通知之后才可用。 |

如果你正在使用另一个界面，通知只会发给那个界面：后端把每条通知只发给一个客户端。

## 设置

用 Ctrl+Shift+S 或侧边栏底部的设置按钮打开。

- **主题：**跟随系统、浅色或深色。
- **语言：**跟随系统、English 或 简体中文。对话区和对话框都有翻译。
- **界面缩放：** `50%`–`400%`（`−` / `+` / *重置*按钮、命令面板，或 `Ctrl+=` / `Ctrl+-` / `Ctrl+0` 按 `5%` 步长调节，也可直接输入任意百分比数值；macOS 上为 `Cmd`）。调整缩放后重启 `ref-gui` 可按原生 `QT_SCALE_FACTOR` 清晰度生效。
- **通知：**总开关和[上面](#通知)说明的三个分类。
- **配置文件：** *重新加载配置*与*编辑 ref.json…*（参见[图形化配置编辑器与多方案](configuration.zh-CN.md#图形化配置编辑器与多方案)）。
- **后端：** 显示当前端点（或*本地（自动）*及脱敏后的令牌）以及*切换后端…*，用于临时切换端点、保存默认端点（`backendUrl` / `backendToken`），或恢复本地自动发现。

设置保存在状态目录（[文件与目录](cli.zh-CN.md#文件与目录)）的 `gui.json` 里，同时保存 `uiScale`（界面缩放比例）、侧边栏显示状态、宽度、各分区折叠状态、自定义分区高度（`sidebar.todoHeight` / `sidebar.runningHeight`）、运行中会话排序（`sidebar.runningOrder`）、已保存的默认后端端点（设置后写入 `backendUrl` / `backendToken`）、悬浮球位置（拖动后写入 `floatingBall`）和窗口大小：

```json
{
  "theme": "system",
  "language": "system",
  "uiScale": 1,
  "notifications": { "enabled": true, "permission": true, "turnDone": true, "turnError": true },
  "sidebar": { "visible": true, "todoExpanded": true, "runningExpanded": true, "historyExpanded": true, "width": 264, "todoHeight": 0, "runningHeight": 0, "runningOrder": [] },
  "backendUrl": "wss://remote.example:7777/",
  "floatingBall": { "screenName": "DP-1", "x": 1840, "y": 980 }
}
```

`theme` 取 `system`、`light` 或 `dark`；`language` 取 `system`、`en` 或 `zh_CN`；`uiScale` 取 `0.5`–`4`（默认 `1`）；`sidebar.todoHeight` 与 `sidebar.runningHeight` 取 `0`（自动）或像素高度；使用本地自动发现时会省略 `backendUrl` 和 `backendToken`，`floatingBall` 会在拖动悬浮球后写入。每次修改都会写入文件（Unix 下权限为 600）。文件无法读取时，会被改名为 `gui.json.bad`，改用默认值，并在设置对话框和窗口角落的提示里说明。有错误的值会逐个被忽略，保持默认值。

## 已知限制

- Windows 和 macOS 上的通知还没有在这两个系统上试过。
- Wayland 下，点击通知后窗口能否前置取决于桌面环境：没有 activation token 时，任务栏图标可能只会闪烁。
- Linux 上 Ctrl+Shift+U 可能被 IBus 的 Unicode 输入占用。按键没有反应时，请关闭 IBus 的这个按键，或使用消息下方的*撤销*按钮或 `/undo`。
- **输入法（IME）：** Linux 安装包除 Qt 自带的 `ibus` 和 `compose` 插件外，还内置了 `fcitx5-qt` 输入法插件，因此 `fcitx5`（`QT_IM_MODULE=fcitx`）和 `IBus` 在原生 Wayland 与 `xcb`（X11/XWayland）下均可直接使用；未设置 `QT_IM_MODULE` 的原生 Wayland 会通过 `zwp_text_input_v3` 工作。
- **Wayland 窗口图标：** Wayland 合成器按桌面 ID 查找窗口图标，因此需要按[安装](../README.zh-CN.md#安装)说明安装 `ref-gui.desktop` 和 `ref.svg` 后才会显示窗口图标。
- **Wayland 悬浮球：** Wayland 合成器掌管全局窗口坐标与 `startSystemMove()`，因此 Linux Wayland 下 `floatingBall` 的 `x`/`y` 持久化与靠边向内锚定会退化为由合成器决定放置位置。
- 在很长的会话中，未加载或被逐出的消息会以估算高度的骨架占位块显示，因此滚动条总长度是估算值，在消息加载或拖动滚动条时可能略有变化。
- 以非 0 退出码结束的 bash 调用，在卡片头里仍显示为完成；退出码在展开的卡片里。
- 对 GUI 没有专门视图的工具，单行摘要按字母顺序列出前三个普通参数，而终端界面按调用中的顺序。
- 工具的参数和输出按 UTF-8 文本显示。
- 没有 `/editor` 和 `/exit` 命令，最后一个会话关闭时 GUI 不会退出。
