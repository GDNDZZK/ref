## 启动

```bash
ref                       # 在当前目录新建会话
ref ~/src/project         # 在另一个目录新建会话
ref -c                    # 继续此目录最近的会话
ref -s ses_01a1…          # 按 id 打开会话（运行中的或历史中的）
ref -w                    # 所有后台会话的分屏视图
ref --agent plan          # 用另一个智能体新建会话
ref --model openai/gpt-5#high -p "Explain src/main.rs"
```

全部参数见[命令行](cli.zh-CN.md#ref)。

## 会话与后端

ref 由两个程序组成。`ref-server`（后端）运行会话：调用 LLM、运行工具、保存历史并处理权限。`ref`（TUI）显示会话并发送你的输入。两者通过本地 WebSocket 通信。

启动 `ref` 时，它会连接到运行中的后端，没有则启动一个。以这种方式启动的后端会在最后一个 `ref` 窗口关闭时退出。其他显示会话的程序，例如浏览器界面（[Web 界面](web.zh-CN.md)），通过同一个 instance 文件找到同一个后端，所以一个会话可以同时在多个界面中打开。由其中一个界面启动的后端，会在最后一个客户端（无论哪种界面）断开后退出。没有窗口显示时，会话仍在后端中运行，因此你可以关闭一个窗口、再打开另一个，从会话当前的进度继续。

- 有 `ref` 窗口连接时，会话处于**前台**，否则处于**后台**。
- 会话保存在 `~/.local/share/ref/sessions/`。`ctrl+x l` 列出运行中的会话和历史会话；打开旧会话会重新加载它。
- 多个 `ref` 窗口可以同时显示同一个会话。

## 界面

- **对话记录**：你的提示、模型的回复、推理内容和工具调用。
- 底部的**输入框**，旁边显示智能体、模型和变体。
- **侧边栏**（`ctrl+x b` 切换显示）：
  - **运行中的会话**，每个会话显示待办进度（`2/5`，全部完成时显示绿色的 `✓3/3`；已取消的项不计数），忙碌时还显示当前轮次已运行的时长。
  - **MCP 服务器**及其状态。
- **状态行**：会话正在做什么，以及本轮运行的时长。时长来自后端，因此切换会话后依然准确。

## 输入提示

| 输入 | 作用 |
|---|---|
| `enter` | 发送。 |
| `shift+enter`、`ctrl+j` | 换行。 |
| `/` | 命令列表（参见[斜杠命令](#斜杠命令)）。 |
| `@` | 模糊匹配的文件列表；插入选中的路径。 |
| `!command` | Shell 模式：在会话目录中运行命令（限时 10 分钟）。命令及其输出作为你的消息加入对话，不触发 LLM 轮次。 |
| `ctrl+v` | 从剪贴板粘贴图片。粘贴图片文件的路径也会附加该图片。 |
| `ctrl+x e` | 在 `$VISUAL` / `$EDITOR` 中编写提示（默认 `vi`，Windows 上为 `notepad`）。 |
| `↑` / `↓` | 提示历史，在输入框为空或光标位于开头时可用。 |
| `esc esc` | 中断会话。 |

**排队的提示。** 会话忙碌时发送的提示会显示在对话记录下方等待，在下一个安全点（当前工具步骤之后）送达。点击 `✕ remove` 可以撤回：它的文本和图片会回到输入框（如果你正在输入，则放在一个空行之后）。如果在此期间已经送达，会弹出提示说明。其他会话排队的消息和提醒也会列出，并标明发送者，但不能撤回。连接到该会话的每个窗口都会实时看到队列变化。

**撤销。** `ctrl+x u`、`/undo` 或提示下方的 `↶ undo` 会删除该提示及其之后的所有内容，并把提示的文本和图片放回输入框。工具修改过的文件**不会**恢复。

## 阅读对话记录

- 每条消息都显示时间：你的提示、每条回复（开始、结束、耗时和 token 数）以及每次工具调用（开始和耗时）。
- 折叠的工具调用显示工具名和模型给出的 `purpose`。点击可查看输入和输出。`ctrl+x d` 展开全部。
- 折叠的推理内容在一行中实时显示最新的字符。`ctrl+x t` 展开。
- 一轮进行中且视图跟随对话底部时，对话底部不会上移。内容变短时，例如重试提示消失、工具的实时输出被结果替换，或展开的推理折叠成一行，空出的行会保留为空白，一轮结束时一次性收回。分屏视图中的每个分块也是如此。只有视图跟随底部时才会开始保留，向上滚动不会增加空白。
- 用鼠标选择文本：拖动选择，双击选词，三击选行。选择不会自动复制。用 `ctrl+c` 或右键复制（对话记录中的选择也可以用 `y` 复制）。在输入框中打字会替换选中的内容。
- 消息下方的 `⧉ copy` 复制其原始 markdown。`ctrl+x y` 复制最后一条回复。

## 快捷键

`ctrl+x` 是前导键：先按它，再按下列键之一。

| 按键 | 作用 |
|---|---|
| `ctrl+x n` | 新建会话 |
| `ctrl+x l` | 会话：运行中的（前台和后台）和历史的 |
| `ctrl+x m` | 当前会话的模型 |
| `ctrl+x a` | 智能体 |
| `ctrl+x c` | 压缩对话 |
| `ctrl+x u` | 撤销最后一条提示 |
| `ctrl+x e` | 在 `$EDITOR` 中编写提示 |
| `ctrl+x x` | 将对话记录导出为 markdown |
| `ctrl+x y` | 复制最后一条回复 |
| `ctrl+x t` | 展开或折叠推理内容 |
| `ctrl+x d` | 展开或折叠工具详情 |
| `ctrl+x b` | 显示或隐藏侧边栏 |
| `ctrl+x w` | 分屏视图 |
| `ctrl+x k`（按两次） | 关闭当前会话 |
| `ctrl+x h`、`ctrl+x ?` | 帮助 |
| `ctrl+x q` | 退出 |

其他按键：`ctrl+p` 打开命令面板，`tab` 切换智能体，`ctrl+t` 切换模型变体，`esc esc` 中断。

## 斜杠命令

| 命令 | 作用 |
|---|---|
| `/new`（`/clear`） | 新建会话 |
| `/sessions`（`/resume`、`/continue`） | 切换会话 |
| `/models`、`/agents` | 选择模型或智能体 |
| `/variant [name]`（`/effort`） | 设置或切换模型变体 |
| `/compact`（`/summarize`） | 压缩对话 |
| `/undo` | 撤销最后一条提示 |
| `/rename NAME` | 重命名会话 |
| `/cd [DIR]`（`/cwd`） | 更改会话目录，或显示当前目录 |
| `/close` | 关闭当前会话 |
| `/close-session [name or id]`（`/kill`） | 关闭运行中的会话 |
| `/export [PATH]` | 将对话记录导出为 markdown（默认为会话目录中的 `ref-session-<id>.md`） |
| `/copy` | 复制最后一条回复 |
| `/thinking`、`/details`、`/sidebar` | 开关 |
| `/watch`（`/split`） | 分屏视图 |
| `/mcp` | MCP 服务器：状态、错误和工具 |
| `/editor` | 在 `$EDITOR` 中编写提示 |
| `/peers`、`/peers-name`、`/peers-inbox`、`/peers-outbox` | 参见[多会话协作](#多会话协作) |
| `/help` | 快捷键和命令 |
| `/exit`（`/quit`、`/q`） | 退出 |

配置中你自己定义的命令也会列出（参见[自定义命令](configuration.zh-CN.md#自定义命令)）。

**`/cd DIR`** 把会话移到另一个目录：绝对路径、相对于当前目录的路径或 `~/…`。项目配置和上下文文件会重新加载，并在对话中加入一条说明告诉模型目录已变更，不触发 LLM 轮次。会话忙碌时不允许执行。之后在此窗口中新建的会话也会从新目录启动。

**`/close`** 关闭当前会话，并切换到剩余运行中会话里最早的一个。没有剩余会话时 `ref` 退出，由 `ref` 启动的后端也随之退出。

## 分屏视图

`ref -w`、`ctrl+x w` 或 `/watch` 并排显示所有运行中的后台会话。

- 此窗口中原来处于前台的会话会转为后台，并获得一个分块。离开分屏视图后它重新回到前台。
- `tab` 或 `alt+方向键` 移动焦点。输入文字并按 `enter` 会向获得焦点的会话发送消息，`esc esc` 中断它，`ctrl+o` 放大它。
- 在分块中输入的 `/close` 和 `/cd` 作用于该分块的会话。
- 每个分块显示它的排队提示（`✕ remove` 撤回一条）。点击工具调用会在分块内显示其输入和输出，再次点击折叠。
- 鼠标滚轮滚动指针下方的分块。

## 多会话协作

会话之间可以互相通信。模型有相应的工具（参见[工具](tools.zh-CN.md#跨会话工具)），你也有在后端运行、不触发 LLM 轮次的命令：

- `/peers`（`/list-agents`）：其他运行中的会话及其状态、智能体、前台或后台、目录和排队的消息。
- `/peers-name [name]`：显示或设置此会话的名称。可以使用任意 Unicode 文本；名称在运行中的会话之间唯一。
- `/peers-inbox`：从其他会话收到的消息，包括仍在排队的。
- `/peers-outbox`：此会话发出的消息，以及每条消息是在排队、已送达还是已读。

具有 `can_spawn` 的智能体（默认是 `build`）可以启动后台会话、给它们分派任务并关闭它们。可以在分屏视图中观察它们。

## 权限与延迟

当工具调用需要权限时，TUI 会显示该调用并询问：

- `a`：允许本次调用
- `s`：在本会话剩余时间内允许该工具的所有调用
- `d`：拒绝；模型会收到通知并继续

工具设置了延迟时，运行前会显示倒计时，按 `esc` 取消该调用。两者都在配置中设置：参见[权限](configuration.zh-CN.md#权限)和[工具延迟](configuration.zh-CN.md#工具延迟)。
